# IoT-Based Fire and Smoke Detection System

## Overview

An IoT-based fire and smoke detection system designed to provide early warning during hazardous situations.

## Features

- Smoke and gas detection using MQ-2 sensor
- Flame detection using IR flame sensor
- Local buzzer alert
- SMS notification through GSM module
- Real-time monitoring
- Low-cost safety solution

## Hardware

- Arduino UNO
- MQ-2 Smoke/Gas Sensor
- Flame Sensor
- GSM Module
- Buzzer
- LED Indicators
- Breadboard
- Jumper Wires

## Software

- Arduino IDE
- Embedded C/C++

## Working

The MQ-2 and flame sensors continuously monitor the environment. When the sensor values cross the predefined threshold, the Arduino activates the buzzer and sends an SMS alert to the registered mobile number through the GSM module.
